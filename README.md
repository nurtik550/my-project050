# Git Merge Conflict Practice

Учебный проект для практической работы по Git Merge Conflict через PyCharm и GitHub.

## Файлы
- `main.py` — итоговый файл после разрешения конфликта.
- `students.py` — дополнительное задание.
- `answers.md` — ответы на 10 контрольных вопросов.

## Итоговый запуск
```bash
python main.py
```
Ожидаемый вывод:
```text
Hello from main and feature
```

## Ветки
В архиве сохранена локальная история Git с ветками `main` и `feature-message`.
